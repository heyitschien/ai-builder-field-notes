# Contributing to AI Builder Field Notes

Corrections, verified links, additional public resources, and short independent notes are welcome.

## Add a new event

1. Copy [the event template](templates/event-template.md) into `events/YYYY-MM-DD-short-event-name/README.md`.
2. Link the organizer's official event page and include the event's date and location.
3. Add separate executive notes, speaker resources, or transcript-derived notes only when useful. Update the root [index](README.md).
4. Clearly distinguish a presenter claim, independent documentation, and a proposed experiment.
5. Open a pull request with a short description of sources and corrections.

## Source and privacy guidelines

- Share public project URLs and official talks. Do not copy entire slide decks, recordings or transcripts unless you have permission.
- No private networking notes, unpublished employment/client information, contact lists, confidential diagrams, credentials, or raw personal conversations.
- **Do not publish names, pictures, or identifying details of children from events without authorization.** Respect any presenter/organizer photography restrictions.
- Paraphrase fairly; use verbatim quotations only when authorized and necessary. Correct obvious speech-to-text typos transparently.
- Verify tool names and hyperlinks when possible. Mark unclear claims as *presenter-reported* or *unverified*.
- Open-source, source-available and commercial are not interchangeable. Check the upstream license before modifying/reusing third-party code.
- Keep personal strategies, private research architectures and work product in private repositories, not here.

## Corrections

Open a GitHub issue or PR and include the exact file/section, the proposed correction and its public evidence (e.g., an official project link). Changes are reviewed before merge.

This repository is an independent community resource, not an official publication from the organizations or presenters it covers.
