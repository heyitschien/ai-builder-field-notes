## What each event folder contains

- `README.md` — what happened, who presented, quick navigation
- `executive-brief.md` — concise lessons and suggested experiments
- `speaker-resources.md` — presenter-by-presenter technologies, GitHub links, documentation, and context
- `transcript-notes.md` — edited notes from available source material; **not** a verbatim transcript unless explicitly labeled otherwise

Future event folders follow `events/YYYY-MM-DD-short-event-name/`. To contribute an event or correction, see [CONTRIBUTING.md](CONTRIBUTING.md) and [the event template](templates/event-template.md).

## Editorial boundaries

This is **independent attendee research**, not an official AI Tinkerers or presenter publication. Notes are paraphrased, with uncertainties flagged. A talk or repository link does not imply a production-ready product, a security guarantee, or endorsement.

- Link to **public projects and documentation**, with license or availability caveats where useful.
- Do **not** upload private recordings, unapproved full transcripts, direct messages, contact details, internal business information, credentials, or photos of minors.
- Distinguish **what speakers said**, **what public docs support**, and **our own suggested experiments**.
- Please suggest corrections via GitHub issues or pull requests.
